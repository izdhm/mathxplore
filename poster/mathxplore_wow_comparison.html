The short answer

MathXplore treats maths, pictures and code as one thing.

Most tools do one of these well. MathXplore makes you move between all three, predict before you see, and learn from the exact mistakes maths students make — and it keeps working with the wifi off.

Four wow moments — 60 seconds in front of a judge

01

Drag a slider

Explore → Quadratic Functions

The parabola moves; its vertex, roots, axis of symmetry and discriminant update live. The Python beside it changes too: a, b, c = 1, 0, -3 becomes a, b, c = -1, 0, -3. That panel is generated from the slider values (src/pages/explore/QuadraticModule.tsx, line 111), and Open in CodeLab carries it over to run and edit.

Why it lands: the judge sees in one gesture that the equation, the picture and the program are the same object.
02

"What happens if a goes from 1 to −1?"

The What If? panel on the same page, scenario 1

The judge has to commit to an answer — the button reads Choose a prediction first until they do. Then Lock in and see what happens: the curve animates against a ghost of the old one, and the lab explains what happened, the concept behind it, and the same change in Python.

Why it lands: committing to an answer makes them care about the reveal — and they find out whether their own intuition was right.
03

Type y = 2x + 3

CodeLab

Most tools answer with SyntaxError: invalid syntax. MathXplore says "Missing multiplication sign — Python cannot read "2x". In maths, 2x means 2 times x, but Python always needs the multiplication sign written out: 2*x", then gives a hint that stops short of the answer, and a "Why Python does this" note.

The engine has lessons like this for other maths habits too: x^2 instead of x**2 · = versus == · square roots of negative numbers · dividing by zero · a function that never returns its answer · counting from 0.

Why it lands: every maths student makes this mistake, and here the mistake becomes the lesson.
04

Switch the laptop to airplane mode

Anywhere in the app

Everything keeps working — navigate, rotate the 3D views, run code — with no account and nothing sent anywhere. The Python engine is part of the page, so there is no download to wait for.

Why it lands: at a Sabah event, where school connectivity is a real problem, this is the moment that turns "nice" into "we could use this".
Set-up tip

Run it from the laptop itself (npm run preview, a localhost address). Airplane mode doesn't affect localhost. A hosted copy would fail on a full page reload with no connection.

·Being honest about it

What's genuinely different

Every ingredient exists somewhere. What's new is the combination, in one page that runs anywhere. Four parts of it are hard to copy:

Errors explained in maths terms

Friendlier Python errors exist (Thonny, Futurecoder, friendly-traceback), but they explain Python in Python's terms. MathXplore's lessons start from the maths habit — "2x means 2 times x", "^ isn't a power" — because the team wrote its own Python engine (about 3,900 lines of TypeScript) and owns every message.

Answers judged by running them

Challenges execute the student's function at test points, so any correct solution passes — including one nobody anticipated. The student's own function is drawn over the goal, so a wrong answer looks exactly as wrong as it is.

One loop around everything

Learn → explore → predict → change → visualise → code → test → understand → create, lit up across the top of every working screen, with the maths, the picture and the Python on the same page.

Zero set-up, zero data

Loads instantly with no login, keeps every record on the device, and costs almost nothing to host because it is just static files. No multi-megabyte Python download, as a Pyodide-based tool needs.

Don't say
  • "The first …" or "the only …"
  • "Improves results by …" — nothing has been measured yet
  • "Full Python"
Say instead
  • "MathXplore brings these together in one place."
  • "It's evidence-ready: the logging for a pre/post-test study is built in."
  • "A deliberate teaching subset of Python."

A judge who knows one counter-example to "the first" will discount everything else you say.

·At the booth

Where judges will push

"Desmos is free and polished. Why use yours?"Desmos teaches the picture, and Python editors teach the code. MathXplore is the bridge between them — with prediction and maths-aware errors — and it works offline.
"GeoGebra already lets you write Python."Yes — PyGgb is the closest idea, and it shows the direction matters. It's an open coding tool; MathXplore wraps the code in a guided loop of lessons, What If? predictions, explained errors and graded challenges, and runs from files the school keeps.
"Does it work?"It hasn't been measured yet, and we don't claim it. The event log, CSV/JSON export and anonymous participant codes are built; the next step is a school pilot with a pre- and post-test.
"Why is there so little content?"6 lessons and 12 challenges is small next to Khan Academy or Brilliant. They prove the method works; teacher authoring tools are on the roadmap.
"Is it real Python?"A deliberate teaching subset: variables, loops, functions, lists, the maths module and plotting — no classes or dictionaries. Its behaviour is tested against real Python (119 engine checks).
Updated since our chat
  • GeoGebra now has a Python app (PyGgb) that builds GeoGebra constructions from Python code. The chat version said graphing apps had "no path to Python"; that was wrong, and PyGgb is now listed as the closest idea.

  • Friendlier error messages exist elsewhere (Thonny, Futurecoder, friendly-traceback). The chat said a Pyodide-based tool "can't rewrite the error messages"; it can. MathXplore's real difference is explaining errors in maths terms, with no download.
